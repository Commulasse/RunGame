# RunGame

Virtuální běžecké závody – web (ukázková verze, data v localStorage prohlížeče).

- `index.html` – celá aplikace (úvod, registrace, deník, administrace)
- `img/`, `fonts/`, `icons/` – obrázky, písma, ikony PWA
- `ocr/` – Tesseract pro čtení screenshotů
- `fit/` – čtení souborů FIT z hodinek

Nasazení: Netlify, statický web bez buildu (`netlify.toml`, publish = kořen repozitáře).
